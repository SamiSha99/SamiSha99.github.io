A framework made for modding purposes that allows modders to create point and click interactivity between the player and the world around them. The system is entirely built upon Hat_HUD a system found in the game with the addition of interactivity through actors and Kismet functionality. The implementation is quick and simple and allows a lot of customizability through changing the mouse look, colors when hovering and size. System interacts through point and click with 3D button actors that the player can drop in the scene and the rest is done through Kismet.

The objective of such framework is to allow for a genre of point and click to be possible in the modding scene, this resulted in different mods using such solution, from FPS related functionality, to interacting with the scene and dragging.
